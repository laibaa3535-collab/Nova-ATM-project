NovaATM Frontend Demo

Files:
- index.html: Complete responsive frontend (HTML, CSS, JavaScript in one file).

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Firefox, or another browser.
3. Demo PIN: 1234

Features:
- PIN login screen
- Dashboard and available balance
- Deposit and withdrawal with validation
- Insufficient-balance check
- Balance inquiry
- Recent transactions and transaction counter
- Responsive layout

Note: This is a frontend-only educational simulation. Data is kept in browser memory and resets on refresh. It is not connected to a real bank or backend.
